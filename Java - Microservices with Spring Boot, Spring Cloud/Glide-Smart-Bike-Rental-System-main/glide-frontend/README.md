# ⚛️ Glide Frontend

React.js frontend for the Glide Smart Bike Rental System.

---

## Technologies

- React.js
- Vite
- Bootstrap 5
- Axios
- React Router
- React Toastify

---

## Features

### Rider

- Login
- Register
- Dashboard
- Wallet
- Wallet History
- Stations
- Available Bikes
- Reservation
- Current Ride
- Ride History

### Operator

- Dashboard
- Station Management
- Bike Management
- Reports

---

## Folder Structure

```
src
├── assets
├── components
├── layouts
├── pages
├── routes
├── services
└── utils
```

---

## Installation

```bash
npm install
```

Run

```bash
npm run dev
```

---

## API

Backend URL

```
http://localhost:8080
```

Axios is used for API communication.

JWT Token is automatically attached to secured requests.

---

## Authentication

- JWT Login
- Protected Routes
- Role Based Navigation
