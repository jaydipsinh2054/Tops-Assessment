Question
Apply MongoDB query operators to retrieve specific subsets of order data from the QuickEats orders collection.

Requirements
1.Insert at least 8 order documents into an orders collection. Each order must include:
	customerId (string)
	restaurantName (string)
	items (array of objects)
	totalAmount (number)
	status (pending, confirmed, or delivered)
	orderDate (ISODate)
2.Write a query using $gt and $eq to find all orders with totalAmount greater than Rs. 400 and status equal to "delivered".
3.Write another query using $in to find orders where the status is either "pending" or "confirmed".
4.Add a projection to return only customerId, totalAmount, and status.
5.Sort the result by totalAmount in descending order and limit it to 5 documents.

Query Using $gt and $eq

    totalAmount: { $gt: 400 },
    status: { $eq: "delivered" }
})

Query Using $in

    status: { $in: ["pending", "confirmed"] }
})

Projection, Sorting, and Limit
db.orders.find(
    {
        status: { $in: ["pending", "confirmed"] }
    },
    {
        _id: 0,

        status: 1
    }
