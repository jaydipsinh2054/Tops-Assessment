Question
Create a MongoDB database and insert a set of restaurant documents to form the data foundation of the QuickEats food delivery platform.

Requirements:
1.Create a database called quickeats_db.
2.Create a collection called restaurants.
3.Insert at least 5 restaurant documents using insertMany().
4.Each document must include:
	name (string)
	cuisine (string)
	city (string)
	rating (number between 1–5)
	isOpen (boolean)
	menu (array of at least 2 items, each with itemName and price)
Use find() with no filter to display all inserted documents.

use quickeats_db

db.createCollection("restaurants")
